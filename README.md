## 30 天验证的三个阶段

- **第 1–7 天：先验证是否有真实需求**，不买量、不扩大产品线。
- **第 8–21 天：用真实问题更新内容和服务卡**，每次只测试一个主要变量。
- **第 22–30 天：核算单笔贡献并决定继续、调整或停止**，不把播放量冒充成交。

## 基础经济账

```
有效咨询率 = 有效咨询数 / 全部自愿咨询数
有效咨询成交率 = 实付人数 / 有效咨询数
单客获客成本 = 获客及投放费用 / 实付人数
贡献金额 = 实收总额 - 退款 - 获客费用 - 其他变动成本 - 服务工时成本
```

分母为 0 时不显示虚假的转化率；不以模拟数字充当真实业绩。
